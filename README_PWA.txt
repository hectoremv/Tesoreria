IMPORTANTE
La PWA necesita publicarse bajo HTTPS para poder instalarse correctamente y usar el Service Worker.
No abras index.html directamente desde el administrador de archivos esperando una instalación PWA completa.

USO DESDE ANDROID
1. Publica el contenido de esta carpeta en un hosting estático HTTPS.
2. Abre la dirección publicada en Chrome.
3. Usa “Instalar app” o “Agregar a pantalla principal”.
4. Abre la aplicación desde el icono creado.
5. Haz un respaldo periódico desde la sección Respaldo.

SEGURIDAD
Los datos quedan en el almacenamiento local del navegador del teléfono.
Si borras los datos del navegador o desinstalas la PWA sin respaldo, puedes perderlos.
