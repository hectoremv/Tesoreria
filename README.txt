Cómo usarla en Android
1) Descomprime el ZIP en una PC o servidor local.
2) Para que Android permita instalarla como PWA y usar el Service Worker, debe servirse por HTTP/HTTPS (no solo abrir index.html como archivo).
   Opción sencilla en una PC de la misma red:
      python -m http.server 8080
   Luego abre en el teléfono:
      http://IP-DE-LA-PC:8080/
3) En Chrome, usa “Agregar a pantalla principal” o el botón “Instalar”.
4) Tras la primera carga, funcionará offline.

IMPORTANTE
- Los datos quedan en el almacenamiento local del navegador/app del dispositivo.
- Haz “Exportar respaldo” periódicamente.
- Borrar datos de Chrome o desinstalar puede eliminar la base local si no existe un respaldo.
